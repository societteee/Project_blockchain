# Руководство по тестированию DApp "Система голосования"

## Обзор тестирования

Данный документ описывает процесс ручного тестирования децентрализованного приложения для голосования. Тестирование включает проверку всех ключевых функций смарт-контракта и веб-интерфейса.

## Предварительные требования

1. Установленный MetaMask или совместимый кошелек
2. Подключение к локальной сети Hardhat (или тестовой сети)
3. Несколько тестовых аккаунтов для проверки различных ролей

## Шаги тестирования

### 1. Развертывание контракта

**Действие:** Развертывание смарт-контракта Ballot в локальной сети
**Команда:** `yarn deploy` или `npm run deploy`
**Ожидаемый результат:**
- Контракт успешно развернут
- В консоли отображается адрес контракта
- Председателем назначается адрес развертывающего
- Создаются 4 предложения для голосования

### 2. Подключение кошелька

**Действие:** Подключение MetaMask к приложению
**Шаги:**
1. Откройте приложение по адресу http://localhost:3000
2. Нажмите кнопку "Connect Wallet"
3. Выберите MetaMask
4. Подтвердите подключение в MetaMask

**Ожидаемый результат:**
- Адрес кошелька отображается в интерфейсе
- Доступны функции взаимодействия с контрактом

### 3. Проверка информации о системе (чтение данных)

**Действие:** Просмотр информации о системе голосования
**Шаги:**
1. Перейдите на страницу /voting
2. Проверьте раздел "Информация о системе"

**Ожидаемый результат:**
- Отображается адрес председателя
- Показывается количество предложений (4)
- Отображается общее количество голосов (0)
- Нет лидирующего предложения (так как голосов еще нет)

### 4. Предоставление права голоса (только председатель)

**Действие:** Предоставление права голоса другому адресу
**Шаги:**
1. Убедитесь, что используете аккаунт председателя
2. В разделе "Предоставление права голоса" введите адрес получателя
3. Нажмите "Предоставить право голоса"
4. Подтвердите транзакцию в MetaMask

**Ожидаемый результат:**
- Транзакция успешно выполняется
- В интерфейсе отображается статус "Успешно"
- Адрес получателя получает право голоса

### 5. Голосование

**Действие:** Голосование за одно из предложений
**Шаги:**
1. Используйте аккаунт с правом голоса
2. Выберите предложение из выпадающего списка
3. Нажмите "Проголосовать"
4. Подтвердите транзакцию в MetaMask

**Ожидаемый результат:**
- Транзакция успешно выполняется
- Количество голосов за выбранное предложение увеличивается
- В интерфейсе обновляется информация о лидирующем предложении
- Статус голосующего меняется на "Проголосовал: Да"

### 6. Делегирование голоса

**Действие:** Делегирование своего голоса другому адресу
**Шаги:**
1. Используйте аккаунт с правом голоса, который еще не голосовал
2. Введите адрес делегата
3. Нажмите "Делегировать голос"
4. Подтвердите транзакцию в MetaMask

**Ожидаемый результат:**
- Транзакция успешно выполняется
- Голос делегирован указанному адресу
- Делегат получает дополнительный вес голоса

### 7. Проверка ошибочных сценариев

**Действие 1:** Попытка голосования без права голоса
**Ожидаемый результат:** Транзакция отклоняется с ошибкой "Has no right to vote"

**Действие 2:** Попытка голосования дважды
**Ожидаемый результат:** Вторая транзакция отклоняется с ошибкой "Already voted"

**Действие 3:** Попытка предоставить право голоса не-председателем
**Ожидаемый результат:** Транзакция отклоняется с ошибкой "Only chairperson can call this function"

**Действие 4:** Попытка делегирования самому себе
**Ожидаемый результат:** Транзакция отклоняется с ошибкой "Self-delegation is disallowed"

## Скриншоты для отчета

### Скриншот 1: Главная страница с подключенным кошельком
**Описание:** Пользователь успешно подключил MetaMask к приложению. В интерфейсе отображается подключенный адрес кошелька и доступные разделы приложения.

### Скриншот 2: Страница голосования с информацией о системе
**Описание:** Отображение информации о системе голосования: адрес председателя, количество предложений, общее количество голосов. Пользователь видит список предложений с текущим количеством голосов за каждое.

### Скриншот 3: Успешное голосование
**Описание:** Пользователь выбрал предложение и успешно проголосовал. В интерфейсе отображается статус "Голос успешно зарегистрирован!", обновляется информация о лидирующем предложении и количестве голосов.

### Скриншот 4: Ошибочный сценарий - попытка голосования без права
**Описание:** Пользователь без права голоса пытается проголосовать. Транзакция отклоняется с ошибкой "Has no right to vote", что демонстрирует работу механизмов безопасности.

### Скриншот 5: Делегирование голоса
**Описание:** Пользователь делегирует свой голос другому адресу. Транзакция успешно выполняется, отображается статус "Голос успешно делегирован!".

### Скриншот 6: Предоставление права голоса председателем
**Описание:** Председатель предоставляет право голоса новому участнику. Транзакция успешно выполняется, отображается статус "Право голоса успешно предоставлено!".

## Автоматические тесты

Для запуска автоматических тестов выполните команду:
```bash
yarn test
```

Тесты проверяют:
- Развертывание контракта
- Голосование и определение победителя
- Делегирование голосов
- Генерацию событий (events)
- Проверки безопасности (require)
- Дополнительные функции чтения/записи
