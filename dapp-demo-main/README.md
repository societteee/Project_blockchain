# Распределённая система голосования на базе Scaffold‑Eth2

## Обзор проекта

Проект реализует **распределённую систему голосования** на блокчейне. Основа системы — смарт‑контракт `Ballot` на языке Solidity, обеспечивающий безопасное, прозрачное и защищённое от фальсификаций голосование с поддержкой делегирования голосов.

Проект построен на шаблоне **Scaffold‑Eth2**, который предоставляет готовую среду разработки и фронтенд‑интерфейс.

**Основные возможности:**
* создание бюллетеней с несколькими вариантами голосования;
* назначение прав на голосование;
* прямое голосование или делегирование голоса;
* определение победившего предложения.

## Смарт‑контракт `Ballot.sol`

Основной контракт реализует механизм голосования с возможностью делегирования голосов.

### Ключевые особенности

* **Роль председателя** (`chairperson`): только председатель может предоставлять право голоса.
* **Вес голоса** (`weight`): накапливается через делегирование, изначально равен 1.
* **Делегирование голосов**: избиратели могут передать свой голос другому участнику (с проверкой на циклы).
* **Подсчёт голосов**: вес каждого избирателя учитывается при подсчёте голосов за предложение.
* **Определение победителя**: автоматически вычисляется предложение с наибольшим числом голосов.

### Структуры данных

```solidity
struct Voter {
    uint weight;      // вес голоса (накапливается через делегирование)
    bool voted;       // true, если участник уже проголосовал
    address delegate; // адрес, которому делегирован голос
    uint vote;        // индекс выбранного предложения
}

struct Proposal {
    bytes32 name;     // название предложения (до 32 байт)
    uint voteCount;   // количество набранных голосов
}
```

### Основные функции

* **`constructor(bytes32[] memory proposalNames)`**  
  Инициализирует бюллетень с заданными названиями предложений. Назначает отправителя транзакции председателем.

* **`giveRightToVote(address voter)`**  
  Предоставляет право голоса указанному адресу (может вызвать только председатель).

* **`delegate(address to)`**  
  Позволяет избирателю делегировать свой голос другому адресу (запрещает самоделегирование и циклы).

* **`vote(uint proposal)`**  
  Фиксирует голос за указанное предложение (учитывает накопленный вес голоса).

* **`winningProposal()`**  
  Возвращает индекс предложения с наибольшим числом голосов.

* **`winnerName()`**  
  Возвращает название победившего предложения.

## Установка и развёртывание

### Предварительные требования

* Node.js (версия 18+)
* yarn (рекомендуется) или npm
* Кошелек MetaMask или аналогичный
* RPC‑эндпоинт (например, Alchemy, Infura или локальный узел)

### Быстрый старт

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/labintsev/dapp-demo.git
   cd dapp-demo
   ```

2. Установите зависимости:
   ```bash
   yarn install
   ```

3. Запустите локальную сеть:
   ```bash
   yarn chain
   ```

4. В другом терминале разверните контракт:
   ```bash
   yarn deploy
   ```

5. В третьем терминале запустите фронтенд:
   ```bash
   yarn start
   ```

6. Откройте http://localhost:3000 в браузере

Подробные инструкции смотрите в [INSTRUCTIONS.md](INSTRUCTIONS.md)

## Использование системы

### Веб-интерфейс

Приложение предоставляет удобный веб-интерфейс для работы с системой голосования:

1. **Главная страница** - Обзор системы и навигация
2. **Страница голосования (/voting)** - Полный функционал:
   - Просмотр информации о системе
   - Голосование за предложения
   - Делегирование голосов
   - Предоставление прав голоса (только председатель)
   - Отслеживание статуса транзакций

### Функции смарт-контракта

#### Чтение данных (view/pure функции):
- `chairperson()` - адрес председателя
- `getProposalCount()` - количество предложений
- `getProposal(uint index)` - информация о предложении
- `getVoterInfo(address voter)` - информация о голосующем
- `getTotalVotes()` - общее количество голосов
- `winningProposal()` - индекс лидирующего предложения
- `winnerName()` - название победителя

#### Запись данных (изменение состояния):
- `giveRightToVote(address voter)` - предоставить право голоса
- `vote(uint proposal)` - проголосовать
- `voteWithWeight(uint proposal)` - проголосовать с генерацией события
- `delegate(address to)` - делегировать голос
- `resetVoting()` - сбросить голосование (только председатель)

#### События (events):
- `VoteCast(address indexed voter, uint proposalIndex, uint weight)` - при голосовании
- `VoteDelegated(address indexed from, address indexed to)` - при делегировании
- `RightToVoteGranted(address indexed voter)` - при предоставлении права голоса

#### Проверки безопасности:
- Модификатор `onlyChairperson()` - проверка прав председателя
- Модификатор `hasRightToVote()` - проверка права голоса
- Проверки `require` для предотвращения некорректных действий

## Вопросы безопасности

* **Контроль доступа**: только председатель может предоставлять права голоса.
* **Защита от циклов**: проверка на циклическое делегирование.
* **Неизменяемость**: после голосования избиратель не может изменить свой выбор.
* **Корректный подсчёт веса**: делегированные голоса учитываются правильно.
