# Инструкции по запуску проекта "Система голосования"

## Установка и настройка

### 1. Установка зависимостей

```bash
# Установите Node.js версии 18 или выше
# Убедитесь, что Node.js установлен:
node --version

# Установите yarn (если не установлен):
npm install -g yarn

# Установите зависимости проекта:
yarn install
```

### 2. Настройка окружения

```bash
# Скопируйте файл .env.example в .env
cp .env.example .env

# Для пакета hardhat:
cd packages/hardhat
cp .env.example .env
cd ../..
```

### 3. Запуск локальной сети Hardhat

```bash
# В одном терминале запустите локальную сеть:
yarn chain

# Сеть будет доступна на http://localhost:8545
```

### 4. Развертывание контракта

```bash
# В другом терминале разверните контракт:
yarn deploy

# Контракт будет развернут в локальной сети
# Адрес контракта и председатель будут выведены в консоль
```

### 5. Запуск фронтенда

```bash
# В третьем терминале запустите фронтенд:
yarn start

# Приложение будет доступно на http://localhost:3000
```

## Настройка MetaMask

### 1. Добавление сети Hardhat

1. Откройте MetaMask
2. Нажмите на сеть вверху (обычно "Ethereum Mainnet")
3. Выберите "Add network"
4. Нажмите "Add a network manually"
5. Заполните параметры:
   - Network name: Hardhat
   - New RPC URL: http://localhost:8545
   - Chain ID: 31337
   - Currency symbol: ETH
   - Block explorer URL: (оставьте пустым)

### 2. Импорт тестовых аккаунтов

1. В MetaMask нажмите на круг с иконкой профиля
2. Выберите "Import account"
3. Используйте приватные ключи из вывода команды `yarn account` или `yarn account:generate`

## Использование приложения

### 1. Подключение кошелька

1. Откройте http://localhost:3000
2. Нажмите "Connect Wallet" в правом верхнем углу
3. Выберите MetaMask
4. Подтвердите подключение в MetaMask

### 2. Навигация по приложению

- **Главная страница (/)** - Общая информация и ссылки
- **Голосование (/voting)** - Основной интерфейс для работы с системой голосования
- **Debug Contracts (/debug)** - Отладка контрактов
- **Block Explorer (/blockexplorer)** - Просмотр транзакций

### 3. Роли пользователей

#### Председатель (Chairperson)
- Может предоставлять право голоса другим адресам
- Является создателем контракта
- Имеет право голоса по умолчанию

#### Голосующий (Voter)
- Может голосовать за предложения
- Может делегировать свой голос
- Может голосовать только один раз

## Устранение неполадок

### Проблема: "Cannot find module"
```bash
# Удалите node_modules и установите заново
rm -rf node_modules packages/*/node_modules
yarn install
```

### Проблема: Контракт не развертывается
- Убедитесь, что локальная сеть запущена (`yarn chain`)
- Проверьте баланс аккаунта развертывания (`yarn account`)
- Проверьте логи ошибок в консоли

### Проблема: Фронтенд не подключается к контракту
- Убедитесь, что контракт развернут (`yarn deploy`)
- Проверьте адрес контракта в консоли развертывания
- Обновите страницу приложения

## Деплой в тестовые сети

### Sepolia Testnet

1. Получите RPC URL от Alchemy или Infura
2. Добавьте его в `.env` файл:
   ```
   SEPOLIA_RPC_URL=ваш_rpc_url
   DEPLOYER_PRIVATE_KEY=ваш_приватный_ключ
   ```

3. Разверните контракт:
   ```bash
   yarn deploy --network sepolia
   ```

4. Обновите `scaffold.config.ts` для использования Sepolia
