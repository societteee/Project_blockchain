# 🗳 Блокчейн-голосование (dApp)

Учебный проект: децентрализованная система голосования. Смарт-контракт на Solidity и веб-интерфейс на Next.js, на основе шаблона Scaffold-ETH 2 и базового контракта `Ballot`.

**Стек:** Solidity, Hardhat, TypeScript, Next.js, Scaffold-ETH 2

## Правила системы

- **Председатель** создаёт бюллетень с вариантами и выдаёт участникам право голоса.
- **Голос** — прямой или **делегированный**: участник может передать свой голос другому. Вес голоса накапливается, циклы делегирования запрещены.
- **Подсчёт** — автоматический, с учётом веса. Победителя определяет контракт.

## Что доработано

**Смарт-контракт `Ballot.sol`:**
- 3 события: `VoteCast`, `VoteDelegated`, `RightToVoteGranted`;
- 2 модификатора доступа: `onlyChairperson`, `hasRightToVote`;
- функции чтения: `getProposalCount`, `getProposal`, `getVoterInfo`, `getTotalVotes`;
- функции записи: `voteWithWeight`, `resetVoting` (только для председателя).

**Тесты (`packages/hardhat/test/Ballot.ts`):** голосование, делегирование, генерация событий, отказы `require` (голос без права, повторный голос, выдача прав не председателем).

**Интерфейс:** страница `/voting` — информация о голосовании, голосование, делегирование, выдача прав, статус транзакций.
